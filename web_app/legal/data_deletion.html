DualMark Studio — Data & Account Deletion Policy

Google Play Data Safety Compliant • Application ID: com.dualmark.studio

Last Updated: October 2026

1. Overview of Zero-Cloud Architecture

DualMark Studio operates entirely as an air-gapped, zero-telemetry local packaging workstation. The application does not maintain external cloud user accounts, does not operate remote databases, and transmits zero packaging identifiers, CTE event logs, or camera frames off your device.

2. Locally Stored Data Types

The application stores the following operational records solely within the device's sandboxed local application storage (IndexedDB / LocalStorage):

  • FDA FSMA Rule 204 Chain-of-Custody CTE Logs: Timestamps, TLCs, GTINs, quantities, and SHA-256 cryptographic hashes.
  • Dynamic Link Resolver Routing Rules: Custom redirect targets and recall kill-switch rules.
  • Licensing Tier State: Active offline license tier marker (Free, Pro, Enterprise).
  • Hardware Preferences: Audio toggle state, Clean Room theme choice, and camera rationale consent flag.

3. How to Request or Execute Complete Data Deletion

Because no data is hosted on external servers, users have complete, instantaneous control over their data:

Option A: In-App Self-Service Purge (Instant)

Within the DualMark Studio mobile application, tap the ⚖️ Legal & Compliance Disclaimers icon in the header, or navigate to Clear All Operational Data. Clicking the purge button will instantly overwrite and wipe all LocalStorage, IndexedDB records, cached document images, and preferences.

Option B: Android System App Storage Clear

You can also delete 100% of the application's stored files via Android Settings:

  1. Open Android Settings → Apps → DualMark Studio.
  2. Tap Storage & Cache.
  3. Tap Clear Storage (or Clear Data). All local CTE archives, routing rules, and license caches are permanently wiped.

Option C: Formal Deletion Inquiry

For formal compliance verification inquiries or enterprise data governance audits, contact:
Data Protection Officer: privacy@dualmark.studio / compliance@dualmark.studio
Response Time: Written confirmation provided within 24–48 hours.
